## Установка на телефон

1. Нажмите кнопку **«Скачать APK»** выше (или перенесите файл `Hanzi-HSK.apk` на смартфон через кабель или мессенджер).
2. Откройте скачанный `.apk` файл в файловом менеджере или браузере на Android.
3. При запросе системы включите разрешение **«Установка из этого источника»**.
4. Подтвердите установку — приложение готово к работе без подключения к сети.

## База слов и иероглифов

В приложении доступно мгновенное переключение между **HSK 3.0 (новым)** и **HSK 2.0 (старым)** стандартами с раздельным сохранением прогресса. Для каждого стандарта можно отдельно подключить блок **«ВУЗ»** — иероглифы и лексику из программы университета (уроки 1–13), не вошедшие в HSK 1–4.

| Стандарт | Всего слов | Уникальных иероглифов | HSK 1 | HSK 2 | HSK 3 | HSK 4 | ВУЗ (доп. блок) |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **HSK 3.0** *(новый)* | 2 049 | 1 101 | 300 | +200 | +500 | +1 000 | +5 иерогл. / +49 слов |
| **HSK 2.0** *(старый)* | 1 256 | 1 068 | 150 | +150 | +300 | +600 | +4 иерогл. / +56 слов |

## Разделы приложения

| Раздел | Возможности |
| :--- | :--- |
| **Черты** | Локальное распознавание рукописного ввода: поиск по точному порядку базовых черт и по общей визуальной форме при слитном написании. |
| **Учить — Интервалы (SM-2)** | Умная очередь интервальных повторений по алгоритму SM-2 (`Снова`, `Трудно`, `Хорошо`, `Легко` с расчётом интервала), возврат забытых слов в текущей сессии, обратный режим `Перевод → 汉字` и счётчик серии дней. |
| **Учить — Тоны и сборка** | Активное вспоминание (Active Recall): различение похожих слогов с разными тонами и сборка многосложных слов из плиток иероглифов. |
| **Учить — Пары** | Визуально-смысловая сетка сопоставления иероглифов и переводов без подсказки пиньиня. |
| **Учить — Тест и Пропись** | Проверка словарного запаса в двух направлениях и каллиграфическая пропись в сетке `田字格` с автоматическим обновлением графика SM-2. |
| **Словарь** | Поиск по иероглифам, пиньиню и русскому переводу с отображением ключа (радикала), числа черт и примеров употребления. |
| **Настройки** | Выбор стандарта (`HSK 3.0` / `HSK 2.0`), подключение нужных уровней (`HSK 1–4`) и блока `ВУЗ`, сетка `田字格` и строгий подсчёт черт. |

## Приватность и автономность

- **Полностью офлайн:** словари, алгоритмы распознавания и контуры написания встроены внутрь APK.
- **Без сетевых разрешений:** в манифесте отсутствует разрешение `INTERNET`, данные никуда не передаются.
- **Без ИИ и внешних API:** приложение работает локально и не расходует платные токены.

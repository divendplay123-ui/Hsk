# Hanzi HSK

Офлайн Android-приложение для изучения китайских иероглифов и лексики **HSK 3.0 и HSK 2.0 (уровни 1–4)**.

## 📲 Скачать и установить APK

- **[⬇️ Скачать Hanzi-HSK.apk (Android 7.0+, ~22 МБ)](apk/Hanzi-HSK.apk?raw=true)**
- Прямая ссылка в репозитории: `https://github.com/divendplay123-ui/Hsk/raw/main/apk/Hanzi-HSK.apk`

### Как установить на телефон
1. Нажмите на ссылку **«Скачать Hanzi-HSK.apk»** выше (если скачиваете с ПК — передайте файл на телефон через Telegram/USB).
2. Откройте скачанный `.apk` файл на Android-устройстве.
3. Если система попросит разрешение, включите **«Разрешить установку из этого источника»** для браузера или файлового менеджера.
4. Нажмите **«Установить»**.

## ✨ Возможности приложения
- **Переключение между стандартами HSK 3.0 (новый) и HSK 2.0 (старый)** прямо в Настройках, Словаре, Заучивании или на экране «Черты» с раздельным сохранением прогресса:
  - **HSK 3.0 (2 000 слов · 1 096 иероглифов)**: HSK 1 (`300`), HSK 2 (`+200`), HSK 3 (`+500`), HSK 4 (`+1 000`)
  - **HSK 2.0 (1 200 слов · 1 064 иероглифа)**: HSK 1 (`150`), HSK 2 (`+150`), HSK 3 (`+300`), HSK 4 (`+600`)
- **Полный словарь иероглифов и слов** с пиньинем, переводом на русский язык, частями речи, ключами (радикалами) и примерами.
- **Поиск по рукописному вводу («Черты»)** — полностью локальное распознавание (без ИИ и интернета) как по порядку черт, так и по общей форме рисунка.
- **Анимация написания** — плавное каллиграфическое прорисовывание черт в сетке `田字格`.
- **Раздел «Учить»**:
  - **Карточки** по словам активного стандарта HSK с разбором входящих иероглифов и фильтром «Только новые».
  - **Тест** («Слово → перевод» и «Перевод → слово»).
  - **Пропись** для тренировки написания иероглифов из слов HSK.
- **Полностью офлайн** — приложение не требует интернета и не расходует токены.

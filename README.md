## Установка на телефон

1. Нажмите кнопку **«Скачать APK»** выше (или перенесите файл `Hanzi-HSK.apk` на смартфон через кабель или мессенджер).
2. Откройте скачанный `.apk` файл в файловом менеджере или браузере на Android.
3. При запросе системы включите разрешение **«Установка из этого источника»**.
4. Подтвердите установку — приложение готово к работе без подключения к сети.

## База слов и иероглифов

В приложении доступно мгновенное переключение между **HSK 3.0 (новым)** и **HSK 2.0 (старым)** стандартами с раздельным сохранением прогресса. Для каждого стандарта можно отдельно подключить блок **«ВУЗ»** — иероглифы, слова и ключи из программы университета (уроки 1–13 и 214 ключей), не вошедшие в HSK 1–4.

| Стандарт | Всего слов и ключей | Уникальных иероглифов | HSK 1 | HSK 2 | HSK 3 | HSK 4 | ВУЗ (доп. блок) |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **HSK 3.0** *(новый)* | 2 229 | 1 303 | 300 | +200 | +500 | +1 000 | +207 иерогл. / +229 слов |
| **HSK 2.0** *(старый)* | 1 437 | 1 276 | 150 | +150 | +300 | +600 | +212 иерогл. / +237 слов |

## Разделы приложения

| Раздел | Возможности |
| :--- | :--- |
| **Черты** | Локальное распознавание рукописного ввода: поиск по точному порядку базовых черт и по общей визуальной форме при слитном написании. |
| **Учить — Карточки** | Повторение лексики активного стандарта HSK с разбором каждого иероглифа в слове, озвучиванием пиньиня и фильтром «Только новые». |
| **Учить — Тест** | Проверка словарного запаса в двух режимах: «Слово → перевод» и «Перевод → слово». |
| **Учить — Пропись** | Каллиграфическая тренировка и пошаговая анимация написания иероглифов из слов HSK в сетке `田字格`. |
| **Словарь** | Поиск по иероглифам, пиньиню и русскому переводу с отображением ключа (радикала), числа черт и примеров употребления. |
| **Настройки** | Выбор стандарта (`HSK 3.0` / `HSK 2.0`), подключение нужных уровней (`HSK 1–4`) и блока `ВУЗ`, сетка `田字格` и строгий подсчёт черт. |

## Приватность и автономность

- **Полностью офлайн:** словари, алгоритмы распознавания и контуры написания встроены внутрь APK.
- **Без сетевых разрешений:** в манифесте отсутствует разрешение `INTERNET`, данные никуда не передаются.
- **Без ИИ и внешних API:** приложение работает локально и не расходует платные токены.
